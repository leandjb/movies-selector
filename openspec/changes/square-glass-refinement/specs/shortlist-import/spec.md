## REMOVED Requirements

### Requirement: Paste control on import inputs
**Reason**: The clipboard paste buttons on the IMDb link and gist inputs are rarely used — visitors paste with native browser shortcuts (Ctrl/Cmd/V). Removing them declutters the form layout and eliminates a test-only feature that adds maintenance cost with no user benefit.
**Migration**: Manual typing and native browser paste (Ctrl/Cmd/V) remain fully functional on all inputs. No replacement control is needed.
